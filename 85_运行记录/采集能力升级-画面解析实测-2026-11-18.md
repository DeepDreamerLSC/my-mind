## 5. 失败与异常清单

### 5.1 阻断级：一段式转写对本地媒体文件必失败（ffmpeg 选项缺陷，未修码）

- 现象：douyin-08 两轮、xhs-02 一轮，`capture_link.py` 退出码 0，笔记门禁记录「音频抽取失败：Option user_agent not found. Error opening input file ~/.cache/my-mind/media/<平台>/<内容ID>/<内容ID>.mp4. Error opening input files: Option not found」。
- 根因定位（未改码）：`capture_link.py` `extract_audio()`（约 L4865-4902）把 `-user_agent`、`-headers` 无条件放在 `-i` 前；dtk/xhs 链路先下载媒体到本地缓存（`local_media_path` 存在时优先本地），对**有效本地 mp4** 输入 ffmpeg 8.1.1 直接拒绝这两个 HTTP 协议选项。手动复现：同一命令带选项 → 同样报错；去掉两选项 → 正常出 mp3。对无效/空文件不触发该报错（在选项应用前就失败于探测），故早前空文件复现不出。
- 确定性证明：douyin-08 原轮+重试轮输出逐字相同；xhs-02 同错；手动 ffmpeg 复现成功。影响范围=所有「媒体已下载到本地」的一段式转写（抖音+小红书全量）；分段转写器 `run_ffmpeg_extract()` 不带这两选项，不受影响。
- 处置：按验收规则不修码、重试额度用尽，如实记录。修复方向（供后续批次）：仅当 `media_url` 为 http(s) 时附加协议选项，或本地文件分支复用分段转写器的干净命令。

### 5.2 样本预期偏差：douyin-07 实为 435 秒长视频

- 简报按「短视频」预期一段式转写；实测 dtk 解析时长 07:15，ffprobe 实测 435.23 秒，> 360s 上限 → 正确入队分段（samples.json 2026-11-17 记录也未登记时长，属登记缺口而非代码缺陷）。

### 5.3 观察项（非缺陷）

- 超短视频（10 秒）仅抽 1 帧，视频内多次界面切换/标注框对比无法覆盖（douyin-08）。
- 12 帧均匀抽样对 7 分钟视频存在瞬间性画面（如终端命令特写）漏抽可能（xhs-05）。
- douyin-08 重试产生重复笔记：`抖音作品-6.md` 与 `-7.md` 内容状态一致，收件箱留有两条同源笔记，待分拣时人工合并即可。
